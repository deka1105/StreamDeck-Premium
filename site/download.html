Get DeskAssist

Two halves: the phone app (the buttons) and the free desktop host (the hands). Everything is free and open source — and everything can be built from source today, straight from the repository.

Phone app

iPhone In App Store review

DeskAssist for iOS has been submitted and is currently in review. When it's live, this page will link straight to the App Store. Until then, you can run it from source on your own device with a free Apple ID:

git clone https://github.com/deka1105/StreamDeck-Premium.git
cd StreamDeck-Premium/mobile && npm install
npx expo run:ios --device  # needs Xcode on a Mac

Android Pre-release

The Android build runs today from source; a Play Store release is in the works (Google requires a closed-testing period first).

cd StreamDeck-Premium/mobile && npm install
npx expo run:android  # needs Android Studio / an SDK

Just want to see it? The app ships with a full demo mode — tap Explore the demo instead on the first screen and everything runs against a simulated Mac, no computer required.

Desktop host

macOS & Windows Run from source

The host is a small Electron tray app that shows the pairing QR and executes your taps. Installers (DMG / installer EXE) will be attached to GitHub Releases; today it runs from source in under a minute:

git clone https://github.com/deka1105/StreamDeck-Premium.git
cd StreamDeck-Premium/desktop && npm install
npm start  # menu-bar / tray app + "Pair a phone" window

On macOS, grant Accessibility permission (System Settings → Privacy & Security → Accessibility) if you want keyboard-shortcut and text tiles — app launching and URLs work without it.

Requirements

  • Phone and computer on the same Wi-Fi network. No account, no cloud — the link is end-to-end encrypted (X25519 + AES-256-GCM).
  • Node.js 20+ for running either half from source.
  • Shell-command tiles are off by default on the host and can only be enabled on the computer itself.
