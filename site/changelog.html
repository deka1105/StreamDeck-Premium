1.1 · build 11 · November 2026

Macros, media, timers — and more than one Mac

  • Macro tiles — one tile runs up to 8 actions in order, with optional pauses between steps. Shell steps still honor the host's shell policy, and every app a macro launches is checked against the allowlist.
  • Media tiles & now playing — play/pause, next, previous (Spotify or Music), volume up/down, mute, and a live volume slider. The deck shows what's playing on your Mac; tap it to pause.
  • Timer tiles — a countdown on the phone (1s to 2h) that fires any action when it hits zero. Tap again to cancel; the tile shows the remaining time.
  • Multiple computers — pair several Macs and switch between them from the deck. Each pairing keeps its own key and replay counter.
  • Profile sharing — share any profile as text (AirDrop, Messages…) and import it on another phone.
  • Shortcut recorder — press the keys in the desktop app and the phone's tile editor offers the captured combo, no syntax to type.
  • Tile palettes & icon packs — five color palettes (Classic, Neon, Dusk, Mono, Sunset) and grouped emoji picks in the editor.
  • A full design pass: entrance and press animations, edit-mode wiggle, live connection dot — all respecting Reduce Motion.

1.0 · build 10 · November 2026

DeskAssist is now completely free

  • The Pro tier and its paywall are gone: unlimited profiles, unlimited pages, unlimited snippets, image tile faces and all five action types for everyone.
  • The payment SDK was removed from the app entirely — no purchase code ships in the binary at all.
  • The website moved to always-on hosting so policy and support links can never go dark.

1.0 · build 8 · November 2026

Review polish

  • New app icon on iOS and Android.
  • Correct export-compliance declaration for the app's encryption, so updates no longer prompt for it.
  • Camera permission flow reworked: the landing screen is always reachable, and the scanner is an explicit step you can back out of.

1.0 · first submission · October 2026

The initial release

  • Pair by QR — an X25519 handshake with end-to-end AES-256-GCM encryption and replay protection. No account, no cloud, no analytics.
  • The deck — a resizable grid (2–5 columns, tiles up to 4×4) of tiles that launch apps, open URLs, fire keyboard shortcuts, type text, or run (opt-in) shell commands.
  • Profiles & pages — named decks with multiple pages, drag-to-reorder, and per-tile emoji, text or image faces.
  • Auto mode — the active profile follows whichever app is focused on your computer.
  • Running apps — a live list of what's open on the computer; tap to focus, or pin any app as a tile.
  • Snippets — a library of saved text that types itself on the computer, with an optional countdown so you can focus the right window first.
  • Demo mode — the whole app against a simulated Mac, so you can try it with nothing installed.
